# Recall: dated memory, checked evidence

“Has it changed since we spoke?” needs a historical baseline and current evidence. A saved answer proves what was said, not what was true. A current price alone cannot establish a change date.

**Storage and recall.** Next.js serves the interface and streaming Node route. Supabase keeps original conversations, UTC timestamps, timezones and full search excerpts. Each completed turn also saves a versioned entity index, structured facts and research trace. Facts carry vendor, plan, amount, currency, billing period, unit, commitment, source URL, quote, observation time and an optional explicit effective date. Legacy prose is never silently promoted into verified facts.

The application retrieves recent context plus owner-scoped historical matches. Chrono/Luxon resolve local dates into UTC windows. PostgreSQL indexes structured entities/facts alongside original prose, preserving vendor names when answer excerpts shrink. Exact-date recall renders original questions directly. Entity indexes supplement the actual conversation; they do not themselves prove a recommendation. Retrieval remains bounded and lexical, so synonyms and long histories can still be missed.

**Bounded graph.** LangGraph runs planning → research → checking → one follow-up round → responding. Exact-date recall and a single dated structured shortlist skip model planning. Ambiguous or legacy cases use Groq to plan retrieval and up to ten queries; additional history permits one replan. Tavily powers the only external agent tool, `web_search`; memory is application context. Queries run at concurrency four with deadlines and cancellation. Pure recall skips research and extraction.

Structured extraction identifies claims and gaps. Code checks literal quotes, amounts, currency, plans and billing terms against supplied excerpts; server-owned URLs/timestamps establish provenance. Missing fields stay unknown, and dollar signs alone do not establish USD. Unextracted price amounts block confident verdicts. Up to three new searches target missing terms, conflicting prices or unsupported passages, followed by one reassessment. Output reserves scale with vendor count to reduce unnecessary Groq quota consumption.

**Correctness and durability.** Code matches historical/current prices by vendor, plan and billing terms. Missing baselines, incomplete/different terms, unsupported usage units, scheduled future prices and conflicts do not produce a change verdict. Temporal comparisons use deterministic wording: different observations, matching samples, conflicts, or insufficient evidence. Matching samples never mean “nothing changed.” Dated releases need an explicit quoted date after the baseline. General answers still stream model prose with citations. Quote checks establish provenance, not source truth or semantic entailment; source omissions and injection remain risks.

Questions are stored before inference. Transactional admission permits one pending turn per conversation; completed request IDs replay without paid work. Answer, facts and trace save atomically before completion. Transient memory reads get one retry with eight-second deadlines. Signed HttpOnly cookies identify evaluation workspaces; every query scopes its owner and RLS blocks browser access. Production needs authentication, retention and distributed quotas.

**Evaluation and tradeoffs.** Eight fixed cases run real Groq against recorded fictional excerpts and local PostgreSQL using the production graph/migrations. Reports score expected facts, recall, uncertainty, citation/coverage checks and first-token/total latency, retaining answers and traces for inspection. These are development assertions, not internet-wide factual accuracy. A separate smoke test checks real Tavily, Supabase persistence and cross-conversation recall.

Next.js keeps HTTP/UI contracts together; LangGraph exposes limits; Supabase supplies durable indexed memory; Groq is the requested provider. I rejected summary-only memory, an unconstrained search loop and a verifier model on every answer. Deterministic comparisons trade flexible prose for defensible verdicts. Extraction adds latency; the 8,000-TPM tier still causes cooldowns. Context limits and a 110-second deadline bound work, not guarantee speed.
